# 1.6 – Melodie weiterführen, Klang aus einer Beschreibung

Wünsche von Martin (29.10.2026), Phase E: „Ich geb eine Melodie vor und sie wird fortgesetzt“ und „Ich sing was, sage, welches Instrument es sein soll und wie es klingen soll, und es wird erzeugt“.

## Wo Claude hilft
- Im Artifact fragt Loopwerk Claude über die Capability `sample` (`src/ai.js`). Der erste Aufruf fragt die Person um Erlaubnis und läuft über ihr eigenes Claude-Kontingent.
- Ohne Claude (GitHub Pages, lokal, abgelehnt) übernehmen Regeln. Die Meldung sagt immer, woher das Ergebnis kommt.
- Was Claude zurückgibt, wird geprüft: Noten aufs 1/16-Raster, Tonumfang C2–C6, nur im angefragten Bereich; Klangname aus der Liste, Effektwerte auf ihre Bereiche begrenzt, unbekannte Optionen fallen weg. Bei unbrauchbarer Antwort greifen die Regeln.

## Melodie-Editor: „✨ Weiterführen“
- Führt die vorhandenen Noten um dieselbe Länge fort, ab dem nächsten vollen Takt, bis höchstens 16 Takte. Das Pattern wächst mit, Clips auch.
- Nochmal klicken ohne Änderung dazwischen ersetzt die letzte Fortsetzung durch eine neue Idee.
- Prompt an Claude: Notenliste (MIDI, Schläge), geschätzte Tonart, Länge, Stil („Motive aufgreifen, singbar, ruhiger Schluss“), Antwort als JSON-Array.
- Regeln: Tonart per Krumhansl-Schmuckler, Motiv als Sequenz auf- oder abwärts oder als Umkehrung (in Tonleiterstufen), letzter Ton auf den Grundton bis zum Phrasenende.

## Einsingen-Feld: „Wie soll es klingen?“ + „Klang bauen“
- Freitext, z. B. „weiche Flöte mit viel Hall“. Wird nach dem Einsingen automatisch angewendet, wenn ausgefüllt, oder per Knopf/Enter.
- Ergebnis: Grundklang (einer der 11), Name des Patterns (von Claude) und Effekte auf den Spuren, auf denen das Pattern liegt. Ein Rückgängig-Schritt (Store-Aktion `applySound`).
- Regeln: Stichwörter auf Deutsch und Englisch (Instrumente; warm/dunkel → Tiefpass, verzerrt/Fuzz/8-Bit → Verzerrer, hell → EQ, fett → Kompressor, Hall/weit → Hall, Echo, wabbernd → Filter-Bewegung, pumpend → Pumpen).

## Grenzen
- „Erzeugt“ heißt: aus den eingebauten Klängen und Effekten zusammengestellt. Es entsteht kein frei synthetisierter Klang und keine Audio-KI.

## Tests
`tests/v15.test.cjs`: Regeln (Länge, Tonart, Schlusston, Ersetzen bei „Nochmal“, Klang aus Stichworten, Rückgängig) und nachgebildetes Claude (Prompt-Inhalt, Bereinigung der Antwort, Klang mit begrenzten Werten).
